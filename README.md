# Lemon Tree

Lemon Tree est une application desktop collaborative centrée sur les projets et les équipes.

## Plateformes prises en charge

- Windows
- macOS
- Linux

## Licence

Lemon Tree est un logiciel propriétaire. Son code source n'est pas distribué sous licence MIT ni sous une autre licence open source. Tous droits réservés.

## Développement

```bash
npm install
npm run desktop -- dev
```

## Validation

```bash
npm run format:check
npm run lint
npm run typecheck
npm test
npm run build
```
